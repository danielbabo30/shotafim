מחבר את חנות ה-WooCommerce שלך לפלטפורמת BridgeAd לצורך שותפויות "תשלום פר רכישה".

== Description ==

התוסף דוגם — בצד השרת — קליקים על קישורי השיוך ורכישות שבוצעו דרך הקישורים והקופונים
הייחודיים של היוצרים שאיתם אתה עובד ב-BridgeAd. הנתונים נשלחים חתומים ל-BridgeAd, שם
מחושבת העמלה שמגיעה לכל יוצר. אין גישה לנתוני החנות מעבר לנדרש למעקב.

* מעקב שיוך שרת-לשרת לשותפויות תשלום-פר-רכישה
* שיוך לפי קישור ייחודי או קוד קופון של היוצר
* עדכון אוטומטי בעת החזר / ביטול
* תור שליחה חוזרת + digest לילי — שום רכישה משויכת לא הולכת לאיבוד
* heartbeat תקופתי לניטור זמינות

== Installation ==

1. התקן והפעל את התוסף (דורש WooCommerce פעיל).
2. WooCommerce ▸ BridgeAd — הדבק את קוד הצימוד מהאזור האישי ב-BridgeAd (מסך "התקנת תוסף המעקב").
3. לחץ "בדיקת חיבור" כדי לוודא שהחנות מצומדת.

== Changelog ==

= 0.2.2 =
* התאוששות אחרי כיבוי והפעלה מחדש: heartbeat מיידי בהפעלה, והשרת מחזיר את החנות ל-ACTIVE (גם אירועים שהגיעו בינתיים לא נזרקים).
* קליק לא חוסם את המבקר: האירוע נכנס לתור ונשלח אחרי שהתגובה נשלחה (או ברקע דרך WP-Cron). מפתח dedup כולל את המבקר.
* שגיאות 401 מובחנות: סטיית שעון מתוקנת אוטומטית (היסט נלמד מהשרת) והבקשה נשלחת שוב; חתימה נדחית → האירוע נשאר בתור עם backoff; "החנות נותקה" → עצירה והודעה במסך ההגדרות. `_bridgead_reported` מסומן רק אם נשלח/נכנס לתור.
* קישור "הגדרות" בשורת הפעולות של התוסף במסך התוספים (רק כש-WooCommerce פעיל ולמי שיש הרשאת manage_woocommerce).
* הצהרת תאימות HPOS ו-Cart/Checkout Blocks.
* הודעת הפעלה בלי ווקומרס: RTL וקישור חזרה לתוספים. תיקוני קטנים: התראת תרגום מוקדמת (cron_schedules), טעינת הזמנה מחדש ב-order-status, נעילה נגד ניקוז תור מקבילי.

= 0.2.1 =
* הודעה ברורה בעברית כשמנסים להפעיל את התוסף בלי ווקומרס פעיל: "תוסף זה מבוסס ווקומרס, יהיה ניתן להתקין אותו לאחר הפעלה של ווקומרס" (הוסרה הכותרת Requires Plugins שגרמה להודעת מערכת מעורבת עברית/אנגלית).

= 0.2.0 =
* פרטיות (SEC-P-13): כתובת ה-IP מצומצמת (IPv4 ‏/24, IPv6 ‏/48) לפני hash; ה-hash של IP / דפדפן / אימייל לקוח מחושב כ-HMAC-SHA256 עם מפתח פרטיות נפרד שנשמר רק בחנות (`hashVersion` = 2).
* תאימות לאחור: עד קבלת המפתח (heartbeat הראשון אחרי העדכון) נשלחים hash בגרסה 1.

* גרסה ראשונה — צימוד, מעקב קליקים ורכישות, החזרים, תור retry, digest, heartbeat, מסך הגדרות.
