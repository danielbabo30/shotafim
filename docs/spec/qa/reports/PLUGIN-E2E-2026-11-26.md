## סביבה
- WordPress 7.1.5, WooCommerce 11.3.1, PHP 8.3.36 (WASM), SQLite (WordPress Playground CLI 3.1.66, מותקן מקומית בתיקיית scratch בלבד). HPOS (custom orders table) **מופעל** (ברירת מחדל של Woo). Checkout: Blocks (Store API). תשלום: COD / שיק (offline).

## מה לא נבדק
- checkout קלאסי (shortcode), גרסאות PHP 7.4/8.0/8.5 ו-WP/Woo ישנות (נבדק רק PHP 8.3, WP 7.1.5, Woo 11.3.1; PHP המקומי 8.6 בבדיקת hash בלבד).
- MySQL אמיתי (נבדק SQLite), WP-Cron אמיתי (הניקוז והדיג'סט הופעלו דרך כלי בדיקה; ה-heartbeat המתוזמן לא המתין 6 שעות).
- Geolocation/CF headers (`country` נשאר null), IPv6, מאחורי proxy/CDN (`X-Forwarded-For` מהמבקר ללא אימות — ראו הערה: `client_ip()` סומך על הכותרת).
- הזמנות עם וריאציות, החזרי שורה, משלוח/מס, multisite, תרגום, caching (page cache עלול להסתיר את `?bgad_ref` מהשרת — דורש בדיקה בחנות עם cache).
- תשלום אמיתי / PSP / כספים — מחוץ לתחום.
- בדיקה ויזואלית בדפדפן של מסך ההגדרות (נבדק HTML/אבטחה בלבד).
